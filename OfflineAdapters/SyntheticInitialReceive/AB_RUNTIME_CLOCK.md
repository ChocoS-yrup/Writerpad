# 실제 시계·저널 I/O 시간 및 대역 세션/통신 취소

2026-09-14. 서버·Auth SDK를 연결하지 않는 오프라인 단계다.

## 시간 의미

`ABRuntimeClock`은 UTC에 Date, 경과 시간에 mach_continuous_time을 사용한다. 로컬 Apple SDK의 mach_time.h에 따르면 이 시계는 절전 중에도 진행한다. UInt64 곱셈/합산 overflow를 확인해 정수 밀리초로 변환한다. UTC는 실행/세션 만료 판정에, 단조 시간은 요청·pass·A/B 간격·적용 전 경과·로컬 단계·전체 경과 한도에 사용한다. UTC나 단조 시계가 뒤로 가면 차단한다. 한 번 관찰한 만료·시간 오류·취소는 해당 실행에 고정하여 시각이 다시 돌아와도 완료 결과가 되살아나지 않는다.

같은 형식의 조절 가능한 시계 대역은 잠금 없이 시스템 시계를 변경하는 도구가 아니다. 테스트 입력만 변경한다. 실제 시계 모드에서는 기존 합성 delayMS/persistenceMS를 양수로 더하거나 sleep으로 바꾸지 않고 거부한다. 실제 작업 경과와 가상 비용을 이중 계산하지 않는다.

예산 시작은 시계 환경을 만든 시점이다. 컨테이너 준비 전의 세션/시각도 고정하여 준비 중 교체·시계 역행을 새 초기값으로 받아들이지 않는다. 보호 컨테이너 준비, 저널 초기화/읽기/쓰기/fsync/재읽기, 검증과 결과 확인에 실제로 걸린 시간을 다음 확인에서 반영한다. reserve와 start의 영속화·재읽기가 요청 한도를 넘으면 아직 대역 통신에 넘기지 않는다. response 저장이 요청/pass 한도를 넘거나 마지막 응답 저장이 적용 전 한도를 넘으면 이후 단계로 넘어가지 않는다. local_start/finish 저장과 완료 후 재검증 비용도 성공 반환에 반영한다.

A/B 간격은 A 마지막 응답부터 첫 B 요청을 transport에 넘기기 직전까지다. 첫 B 응답 자체의 대기 시간은 요청/pass 예산에 속한다. 적용 전 경과는 B 마지막 응답부터 local_start 기록 확인까지이며 이후 로컬 단계 시간을 별도 판정한다. 한도와 같아진 시점도 초과로 차단한다.

동기 파일 I/O와 fsync의 실행 중간을 강제 중단하지는 않는다. 호출 전후의 정책 확인과 다음 통신/성공 반환 차단을 제공한다. 오류 뒤 보존용 stop 쓰기·잠금 해제는 성공이나 요청 재개가 아니며, 정리 시간까지 OS가 deadline 안에 끝낸다는 보장은 없다. 별도 io_duration 필드를 원래 Windows 형식에 추가하거나 호환 완료로 표시하지 않는다.

## 세션과 취소

`ABSessionDouble`은 합성 식별자·세대·만료만 보관하는 잠금 대역이다. 실제 세션/토큰을 읽지 않는다. 같은 ID로 교체해도 세대를 변경한다. 실행 중 ID/세대/만료가 바뀌면 차단하며 만료 연장을 자동 로그인 갱신으로 받아들이지 않는다. 자연 만료도 별도로 차단한다.

합성 transport는 취소 전파를 받는 잠금 상태와 before-send/in-flight/before-delivery 주입 지점을 가진다. 실제 URLSession이나 취소 가능한 HTTP task는 없다. 사전 취소는 차감 전에 차단하며, 예약 뒤 취소·만료·세션 교체는 예약 비용을 유지한다. 응답을 넘기기 전에 다시 확인해 늦은 응답을 raw/완료로 수용하지 않는다. finish 저장 중이나 완료 뒤 취소도 결과 재게시를 차단한다.

실제 HTTP 전송의 중간 취소, 연결 종료 확인, Auth refresh와 앱 재시작의 실제 세션 재결합은 아직 미검증이다. 대역 호출 수는 실제 HTTP 수가 아니다.

## 보호 컨테이너 연결

기존 `ProtectedABJournalWork.run()`의 기본 합성 모드는 이전 검사의 결정성을 위해 유지한다. 새 `runWithSystemClock()`은 실제 시계와 합성 세션/transport를 사용하며 iOS controller의 명시적 합성 저널 호출 경로를 여기에 연결했다. 자동 실행·새 UI 버튼·실제 기기 실행은 없다.

이 경로의 로컬 합성 시험 한도는 요청 5초, pass 30초, A/B 간격 5초, 적용 전 5초, 로컬 5초, 전체/실행 만료 60초다. 합성 세션 만료도 해당 실행 만료와 같다. 이는 실제 원격 실행 승인·새 로그인·실제 수신 정책 확정이 아니다. 시작 시간이 달라져도 이미 존재하는 저널을 초기화하거나 재실행하지 않는다.

기존 컨테이너 lease/파일 보호, HTTP 14 안의 Auth 대역 2, 사전 차감·실패 유지·재시작 차단, 원본과 종료 기록 보존은 유지한다. 실제 baseline/서버 출처/최신성/profile/Windows 체인 호환·실기기 파일 보호의 미검증 항목을 승격하지 않는다.
