# iPad 일반 복구 시험과 진단 로그 수집

대상은 이미 설치한 **ChocoS Debug, ab89384**다. 이후 코드 수정의 설치 여부와
별개로 이 빌드에는 복구 JSONL 기록 기능이 있다. 실제 계약 관문을 닫은 채
기존 방식의 원고 저장·자동 복구를 확인하는 절차이며 계약 전송 시험은 아니다.
Windows 최신 수정의 설치 여부나 실제 계약 전송 성공을 증명하지 않는다.

## 사용자가 진행할 순서

1. **ChocoS Debug**를 열고 시험용 작품의 원고 하나에 들어간다. 동기화 설정의
   계약 관문과 계약 배치 수동 전송 버튼은 조작하지 않는다. 평소 서버 동기화가
   되는 Wi-Fi에서 `서버 동기화됨` 표시를 먼저 확인한다.
2. 현재 시각을 초 단위까지 적는다. 원고 끝에 `복구 시험 A`를 입력하고 로컬
   저장 표시를 확인한다. 중요한 본문을 지우거나 교체하지 않는다.
3. 제어 센터에서 비행기 모드를 켜고 **Wi-Fi도 꺼졌는지** 확인한다. 원고에
   `오프라인 저장 B`를 추가하고 로컬 저장이 끝날 때까지 기다린다. 오프라인이어도
   집필과 로컬 저장이 가능한지 적는다.
4. 비행기 모드를 끄고 Wi-Fi를 다시 연결한다. 연결을 되살린 시각을 적고 같은
   원고 화면에서 기다린다. `서버 재연결 중` 등 중간 표시와 `서버 동기화됨`으로
   바뀐 시각을 기록한다. 작품 목록으로 나갔다가 다시 들어오지 않는다.
5. 2분 안에 복구되면 걸린 시간을 기록한다. 2분이 지나도 복구되지 않으면
   현재 표시와 시각을 적고 **반복 시험 대신 그 상태로 알려 준다.** 입력한
   문장은 그대로 둔다. 2분은 이번 기록의 관찰 한계이며 정상 복구 시간의
   합격 기준으로 확정한 값은 아니다.
6. 복구된 경우 로컬 저장 완료를 확인한 뒤 앱 전환기에서 앱을 종료하고 다시
   연다. 같은 작품·원고의 A/B 문장이 모두 남아 있는지, 서버 상태가 다시
   정상으로 돌아오는지와 그 시각을 적는다.
7. iPad를 Mac에 연결하고 잠금을 해제한 뒤 이 작업에 다음을 알려 준다.
   `시험 완료, 통신 복구 시작 시각 / 서버 동기화됨 시각 / 재실행 시각 /
   A·B 문장 보존 여부`. Codex가 기기에서 진단 파일을 읽어 수집한다.

한 번의 기록이면 된다. 추가 재현은 로그를 분석한 뒤 필요할 때 진행한다.
진단 기록에는 원고 본문·작품 이름·토큰을 넣지 않는다. 사용자도 본문을 첨부할
필요가 없다. 서버 반영 자체의 추가 증거가 필요하면 Windows에서 A/B만 읽어
확인하되, 같은 원고를 동시에 편집하지 않는다.

## Codex가 수집할 파일과 판독 범위

Debug 앱 컨테이너 `com.chocos.writerpad.debug`에서 다음 두 파일을 복사한다.

- `Library/Caches/SyncDiagnostics/recovery.jsonl`
- `Library/Caches/SyncDiagnostics/recovery.previous.jsonl` — 아직 회전 전이면 없을 수 있다

`devicectl device copy from`의 appDataContainer 읽기로 수집하며 앱이나 컨테이너를
삭제하지 않는다. 로컬 `build/recovery-device-<수집시각>/`에 보관하고 파일 SHA-256,
수집 시각, 설치 커밋/바이너리 식별을 함께 남긴다. 원본 JSONL은 Git에 넣지 않는다.
앱 실행 때마다 session ID가 바뀌므로 session ID 안에서 monotonic 시각으로
구간을 계산하고, 재실행 전후는 사용자 기록과 wall-clock 시각으로 연결한다.

network → auth → handshake → pull/legacyUpload → UI 사건을 대조한다. 기록되지
않은 시간 구간을 임의로 특정 단계의 지연이라고 단정하지 않는다. 이전의
30초~2분 지연은 당시 로그가 없어 원인이 확정되지 않았다. 이번 기록으로
원인이 확인된 경우에만 별도 진단 결과를 회신한다.

로그 파일 수집·실기기 복구 시험과 격리 저장소의 계약 쓰기 차단 시험은 각각
별도 결과로 보고한다. 실제 계약 관문 개방·서버 설정 변경·계약 쓰기는 이
절차에 포함되지 않는다.
