# 조합 완료 규칙과 장면 전환선 4-4

## 사용자 확정 규칙

- 세 번째 마침표를 직접 입력하면 직전 `..`와 합쳐 중간점 말줄임표 `⋯`로 바꾼다.
- 한글 IME에서 방금 조합을 끝낸 `ㄴㄴ`을 `「」`로 바꾸고 커서를 가운데 둔다.
- 한글 IME에서 방금 조합을 끝낸 `ㄱㄱ`을 `『』`로 바꾸고 커서를 가운데 둔다.
- `「|」`·`『|』`에서 Backspace를 누르면 빈 인용부호 쌍을 함께 삭제한다.
- `「|」`·`『|』`에서 Enter를 누르면 닫는 인용부호 뒤에 줄바꿈하고 커서를 다음 줄로 옮긴다.
- 명시적으로 별표 하나를 입력하면 정확히 `\n\n * * *\n\n`을 삽입한다.
- 붙여넣은 별표와 기존 원고의 별표는 자동 변환하지 않는다.
- 붙여넣은 마침표·자음과 기존 원고만으로는 단축 규칙을 실행하지 않는다.
- 전환선 바로 뒤의 Backspace 또는 바로 앞의 Delete는 전환선 전체를 삭제한다.

## IME 경계

- `CompositionSessionTracker`는 `markedTextRange`가 유지되는 동안 최초 UTF-16 위치를 보존한다.
- iPad가 두 번째 자음을 marked text로 계속 유지하면 단축 패턴이 완성된 경우에만 `unmarkText()`로 해당 조합을 확정한다.
- marked text를 사용하지 않는 Bluetooth 입력은 두 번째 직접 자음 입력 사건에서 같은 규칙을 적용한다.
- marked text가 완전히 사라졌을 때 마지막 커서까지를 최근 확정 범위로 반환한다.
- `TextRuleEngine`은 최근 확정 범위의 끝이 정확히 `ㄴㄴ` 또는 `ㄱㄱ`일 때만 치환한다.
- 커서 주변의 기존 원고나 붙여넣기 문자열을 뒤로 검색해 오작동시키지 않는다.
- 조합 완료 치환을 먼저 끝낸 뒤 pending 문서 전환을 실행한다.

## Undo와 무결성

- 인용부호 변환, 전환선 삽입, 전환선 전체 삭제는 각각 한 Undo/Redo 단위다.
- 특수 인용부호 빈 쌍 삭제와 닫는 부호 뒤 Enter도 일반 괄호와 같은 Undo 규칙을 사용한다.
- 전체 본문을 재할당하지 않고 `textStorage`의 최소 UTF-16 범위만 교체한다.
- `스마트 쌍 입력` 설정을 끄면 조합 완료 규칙과 전환선 규칙도 함께 우회한다.

## 검증 상태

- IME marked range 이동·확정 fixture 통과
- 한글·이모지 앞 UTF-16 범위와 `ㄴㄴ`·`ㄱㄱ`·`...` 치환 통과
- `「」`·`『』` 빈 쌍 삭제, Enter, 본문·커서 Undo 복원 통과
- 설정 off, 기존 원고 범위 제외, 별표 붙여넣기 우회 통과
- 전환선 양쪽 전체 삭제와 Undo 통과
- iPad M5 시뮬레이터의 실제 UIKit 입력 경로에서 별표 전환선 확인
- 수정 후 실제 iPad 소프트웨어·Bluetooth 한글 키보드 재검증 대기
