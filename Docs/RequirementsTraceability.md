# 요구사항 추적표 — 로컬 개발 1~7단계

상태 값은 `계획`, `구현 중`, `검증 완료`, `보류`를 사용한다. `검증 완료`는 현재 단계에서 마련한 기반이 자동 검사에 통과했다는 뜻이며, 이후 단계에서 관련 구현이 확장되면 다시 회귀 검증한다.
