# 스마트 쌍 입력 4-3

## 구조

- `TextRuleEngine`은 UIKit과 독립된 순수 Swift 규칙 엔진이다.
- 현재 본문, UTF-16 선택·변경 범위, 입력 문자열, 설정, 조합 상태를 받아 처리 여부와 최소 편집 연산, 새 선택 범위를 반환한다.
- `iPadTextEditor.Coordinator`는 `UITextViewDelegate` 입력을 요청 모델로 바꾸고 결과를 `SmartTextView`에 전달하는 얇은 어댑터만 담당한다.
- `markedTextRange`가 존재하면 모든 스마트 쌍 규칙을 우회해 한글 조합을 방해하지 않는다.

## 입력 규칙

- `'`, `"`, `[`, `(`, `{`를 입력하면 닫는 기호를 함께 넣고 커서를 가운데 둔다.
- 선택 영역이 있으면 선택한 원문을 쌍으로 감싸고 내부 선택을 유지한다.
- 커서 바로 뒤와 같은 닫는 기호를 입력하면 문자를 중복하지 않고 기호 뒤로 이동한다.
- 빈 쌍 가운데서 Backspace를 누르면 쌍 전체를 삭제한다.
- 닫는 기호 바로 앞에서 Enter를 누르면 닫는 기호 뒤에 줄바꿈을 삽입한다.
- 붙여넣기는 글자 수와 관계없이 스마트 입력으로 해석하지 않는다.
- 설정의 `스마트 쌍 입력`을 끄면 모든 규칙을 우회한다.
- 세 번째 마침표 직접 입력은 직전 `..`를 중간점 말줄임표 `⋯`로 바꾸며 붙여넣기는 우회한다.

## 문자열 무결성

- 외부 범위는 `TextCursorState`의 UTF-16 위치로 전달한다.
- `NSRange`를 Swift `String.Index`로 변환한 뒤 Character 경계를 다시 검사한다.
- 이모지 surrogate 또는 결합 문자 내부, 문서 범위를 벗어난 위치는 처리하지 않고 UIKit 기본 입력에 맡긴다.
- 처리된 입력은 전체 본문 재할당 없이 `textStorage`의 필요한 범위만 교체한다.

## Undo

- 스마트 쌍 삽입·감싸기·빈 쌍 삭제·닫는 기호 뒤 줄바꿈은 각각 한 Undo 단위다.
- Undo 시 제거한 문자열과 이전 선택을 복원하고, 같은 역연산 등록으로 Redo도 보장한다.
- 닫는 기호 건너뛰기는 본문을 바꾸지 않고 선택만 이동한다.

## 검증

- 다섯 쌍의 빈 선택 자동 입력
- 한글·이모지 선택 영역 감싸기
- 닫는 기호 건너뛰기, 빈 쌍 삭제, 닫는 기호 뒤 줄바꿈
- 조합 중·설정 off·붙여넣기 우회
- 문서 시작·끝과 잘못된 UTF-16/이모지 내부 범위
- 한 번의 Undo/Redo로 본문과 선택 복원
- iPad M5 시뮬레이터 UI에서 `한글🙂(` 입력 결과 `한글🙂()` 확인

4-4 조합 완료 규칙과 장면 전환선 확장은 `CompositionCompletionRules.md`에 기록한다.
