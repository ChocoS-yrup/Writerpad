# 1~7단계 완료 조건

각 단계는 자동 테스트가 통과하고 실행하지 못한 실제 기기 검증이 명확히 표시된 경우에만 완료한다.

## 1단계 — Xcode 기반과 로컬 아키텍처

- iPadOS 17 이상 앱·테스트 타깃이 빌드된다.
- App, Domain, Data, Features, Platform, Sync, Tests 경계가 존재한다.
- SwiftData에 본문이 저장되지 않는다.
- UUID와 상대 경로가 분리된다.
- 서버 기능은 protocol과 no-op adapter뿐이다.
- AI·플롯 고정 기능과 Supabase 패키지가 없다.

현재 1-2 검증 결과:

- iPadOS 17.0, iPad 전용 앱·테스트 타깃 빌드 성공
- SwiftData 메타데이터 저장·조회와 서버 no-op 경계 테스트 2개 통과
- Mac Catalyst 호환 빌드 성공
- 실제 iPad 서명·한글 입력 검증은 후속 완료 조건으로 유지

현재 1-3 검증 결과:

- Domain에서 SwiftUI·UIKit·SwiftData import가 없음을 정적 검사
- `Project`, `DocumentNode`, `BackupSnapshot`, `SaveState`와 편집기 상태 값 구현
- 작품·문서·백업 UUID와 상대 경로를 별도 타입으로 분리
- 저장소·파일 저장·백업·검색·추출·시계·UUID·해시 protocol 정의
- 서버 상태는 미설정·로컬 전용·향후 연결의 최소 경계만 정의
- Codable 왕복·UUID 유지·본문 미중복·저장 상태 전이 포함 전체 테스트 9개 통과

현재 1-4 검증 결과:

- `WriterPadSchemaV1` 1.0.0과 빈 명시적 migration plan 구성
- 작품·문서·앱 상태·작품별 화면 상태 SwiftData 레코드 분리
- `SwiftDataMetadataRepository` actor가 Project·Document·Workspace protocol 구현
- 마지막 작품, 좌우 문서, 활성 편집기, 바인더 너비, 펼친 폴더, 문서별 커서 복원
- 누락 부모·자기 부모·다른 작품 부모·비폴더 부모 저장 거부
- 손상 kind·hash·휴지통 복원 정보·화면 상태를 숨기지 않고 오류로 보고
- 실제 파일 저장소 재오픈을 포함한 전체 테스트 15개 통과
- iPad Pro 11-inch 시뮬레이터와 Mac Catalyst 빌드 통과

## 2단계 — 로컬 문서 저장과 작품 관리

현재 2-1 검증 결과:

- `PathPolicy`에서 금지 문자 9개, 제어 문자, 끝 공백·마침표, 점 경로 거부
- 확장자·대소문자와 무관하게 Windows 예약 이름 거부
- NFC 정규화와 대소문자 비구분 충돌 키 적용
- 파일명 255·상대 경로 1,024 UTF-16 단위의 교체 가능한 임시 상한 적용
- `ProjectPathResolver`가 Application Support/WriterPad/Projects 아래 경로를 전담
- 휴지통은 `메인/휴지통`에만 생성하고 플롯·메인 스토리 틀·전환직전은 생성하지 않음
- 절대 경로·`..`·빈 구성 요소·심볼릭 링크 루트 탈출 거부
- 한글 작품 구조 생성과 설정 보존 재실행 멱등성 테스트 통과
- iPad Pro 11-inch 시뮬레이터 전체 테스트 28개 및 Catalyst 빌드 통과

현재 2-2 검증 결과:

- `LocalDocumentStore` actor가 엄격한 UTF-8 읽기와 문서별 저장 직렬화 구현
- 같은 폴더의 고유 임시 파일에 전체 쓰기·`fsync`한 후 `rename`으로 교체
- SHA-256·수정 시각·경로를 SwiftData에 반영하는 전용 경계 구현
- 메타데이터 실패 후 해시 검증 기반 재실행 재조정과 오래된 임시 파일 정리 구현
- 실제 원고 없이 한글·이모지·대용량·동시성·장애 주입·재실행 복구 테스트 통과
- iPad Pro 11-inch 시뮬레이터 전체 테스트 39개 통과
- Mac Catalyst arm64·x86_64 호환 빌드 통과

현재 2-3 검증 결과:

- 숨김 임시 작품 컨테이너에서 전체 구조를 완성한 뒤 정식 경로로 승격
- SwiftData 작품 메타데이터와 원자적 로컬 카탈로그의 역할 분리
- 동일 생성 요청 멱등성, 대소문자·NFC 충돌 덮어쓰기 방지
- 이름 변경 저널과 앱 재실행 완료·롤백 복구 구현
- 사용자 지정 순서와 마지막 활성 작품 복원 구현
- 삭제 확인 후 실제 제거 없이 삭제 대기 상태로만 전환
- 후속 관리 작업을 위한 안전한 작품 루트 설명자 구현
- 목록·생성·이름 변경·순서·삭제 확인 최소 SwiftUI 연결
- iPad Pro 11-inch 시뮬레이터 전체 테스트 49개 통과
- Mac Catalyst arm64·x86_64 호환 빌드 통과

현재 2-4 검증 결과:

- 파일 선택과 security-scoped resource 수명을 가져오기 서비스에 얇게 연결
- 원본 전체 읽기 전용 검사 후 치명 오류·경고 `ImportReport` 생성
- UTF-8·필수 구조·중복 작품·중복 화·권화 이름·접근·숨김·알 수 없는 항목·정규화 충돌 검사
- 검사 뒤 원본 변경 시 콘텐츠 지문 비교로 재검사 요구
- 임시 프로젝트 전체 복사, 문서 UUID·TXT SHA-256 생성, SwiftData 일괄 등록 후 정식 승격
- 중간 실패와 앱 재실행에서 복사본·메타데이터 전체 롤백 또는 완료 상태 복구
- 플롯·메인 스토리 틀을 일반 사용자 폴더로, `백업/전환직전`을 병합 없는 레거시 백업으로 보존
- 실제 제공 원고를 사용하지 않는 정상·오류·400화·복사 실패 fixture 테스트 9개 통과
- iPad Pro 11-inch 시뮬레이터 전체 테스트 58개 통과
- Mac Catalyst arm64·x86_64 호환 빌드 통과

- 기본 작품 폴더에 플롯·메인 스토리 틀 고정 폴더가 없다.
- 휴지통 실제 경로가 Windows와 같은 `메인/휴지통`이다.
- Windows 금지 문자·예약 이름·정규화 충돌·경로 탈출을 거부한다.
- UTF-8 TXT 원자 저장 실패 시 기존 원고가 보존된다.
- 작품 생성·이름 변경이 중간 실패에서 복구된다.
- Windows 작품 가져오기가 원본을 수정하지 않고 전체 롤백을 지원하며 `메인/플롯`·`백업/전환직전`을 보존한다.

## 3단계 — 바인더와 권·화

현재 3-1 검증 결과:

- 고정 최상위 폴더 8개를 정해진 순서로 제공하고 원고를 첫 번째로 고정 표시
- 플롯·메인 스토리 틀을 포함한 사용자 폴더를 고정 항목으로 승격하지 않고 일반 표시
- SwiftData UUID·부모·사용자 순서와 파일 시스템 상대 경로 결합
- 작품 진입 시 `메인` 직계 하위만, 펼침 시 해당 폴더 직계 하위만 비동기 지연 로딩
- 일반 영역의 저장된 사용자 순서와 원고 영역의 권·화 숫자 자연 정렬, 화면에서만 `.txt` 확장자 숨김
- 파일 크기로 빈 문서·작성 문서 구분, SHA-256으로 외부 TXT 이름 변경 조정
- 펼침 상태 저장·필요한 가지 복원과 접힌 형제 미로딩 검증
- 1,000화와 보조 폴더 fixture를 포함한 바인더 테스트 6개 통과
- iPad Pro 11-inch 시뮬레이터 전체 테스트 64개 통과
- Mac Catalyst arm64·x86_64 호환 빌드 통과

현재 3-2 검증 결과:

- UI·파일 I/O와 분리된 순수 Swift `BinderRuleService` 구현
- 생성·이름 변경·이동·드롭·순서 변경마다 허용 또는 사용자용 거부 이유 반환
- `N권`, `NNN화.txt`, 1,000화 이상, 앞자리 0, ASCII 숫자, 유사 문자, 확장자 대소문자 경계 확정
- 권 이름 잠금과 화 숫자+`화` 접두사 보호, 원고 전체 중복 화 번호 거부
- 원고 안팎 이동 금지와 권·화 구조가 깨지는 목적지 거부
- 일반 영역에는 Windows 안전 이름과 정규화 충돌 외의 원고 제약 미적용
- 원고 권·화 숫자 자연 정렬을 저장 사용자 순서보다 우선 적용
- Windows 가져오기의 권·화 검사를 같은 규칙 파서로 통합
- 표 기반 원고 규칙 테스트 9개와 가져오기 경계 테스트 1개 추가
- iPad Pro 11-inch 시뮬레이터 전체 테스트 74개 통과
- Mac Catalyst 호환 빌드 통과

현재 3-3 검증 결과:

- 일반 폴더·TXT 생성, 이름 변경, 사용자 순서, 폴더 드롭, 휴지통 이동 명령 구현
- 모든 변경 전 `PathPolicy`와 `BinderRuleService` 판정, 고정 항목·열린 문서·자기 하위·미확정 드롭 차단
- 파일 이동과 SwiftData 일괄 갱신 사이의 3단계 복구 저널과 재실행 완료 검증
- 중복 이름을 덮어쓰지 않고 Windows 안전 대안 이름 제안
- 이름 변경·이동 후 루트와 200개 TXT 하위 트리의 `document_id` 유지
- 길게 누르기·우클릭 메뉴와 드래그 앤 드롭 화면 연결, 비활성 명령 이유 표시
- 3-3 전용 테스트 9개와 iPad Pro 11-inch 시뮬레이터 전체 테스트 83개 통과
- Mac Catalyst 호환 빌드 통과

현재 3-4 검증 결과:

- 원고 최상위 컨텍스트 메뉴에 `새 권 추가` 명령 연결
- 유효한 최고 `N권`+1과 권당 25개 화 범위 계산, 0권·번호 공백·잘못된 권 이름 제외
- 고유 숨김 임시 폴더에 빈 UTF-8 TXT 25개를 준비한 뒤 정식 권 폴더로 한 번에 승격
- 권 1개와 화 25개의 UUID·SHA-256 메타데이터를 SwiftData 한 거래로 등록
- 25개 각 파일 생성 지점 실패에서 임시·정식 파일, 메타데이터, 저널 전체 롤백
- 정식 폴더 승격 직후 중단을 저널로 재실행 복구하고 기존 권·전역 중복 화 덮어쓰기 차단
- 작품별 동시 두 번째 생성 요청 차단, 성공 후 새로고침·새 권 펼침·첫 화 열기 의도 반환
- 서버 작업 없이 로컬 no-op `FutureChangeNotifying` 일괄 생성 사건 호출
- 1,000화 이후 네 자리 이상 파일명 자연 확장 검증
- 3-4 전용 테스트 8개와 iPad Pro 11-inch (M5) 시뮬레이터 전체 테스트 91개 통과
- Mac Catalyst 호환 빌드 통과

- 현재 3-5 검증 결과:

- 앱 실행·재실행은 항상 작품 목록에서 시작하고, 작품을 열면 바인더·편집기 자리표시자만 표시
- 세로·좁은 폭에서 바인더를 닫고 상단 버튼 하나로 다시 열기
- 작품 변경으로 목록 화면 복귀, 검색·좌우 분할·TXT 추출·백업·설정의 타입 안전한 진입점과 작은 로컬 저장 상태 배지 제공
- 바인더 8개 고정 항목, 선택 반영, 길게 누르기 메뉴를 UI 테스트로 확인
- Dynamic Type 접근성 크기, VoiceOver 식별자, 키보드 포커스 적용
- 작업 화면 `…` 메뉴에서 다크 모드 on/off와 시스템 모드 추종 제공
- iPad Pro 11-inch (M5) 시뮬레이터 단위 테스트 91개와 UI 테스트 4개, 총 95개 통과
- Mac Catalyst arm64 호환 빌드 통과

- 고정 최상위 항목 8개가 올바른 순서로 표시된다.
- 일반 사용자 폴더와 TXT 문서를 만들고 이동할 수 있다.
- 원고는 `N권/NNN화.txt` 이외 구조를 거부한다.
- 새 권 25개 화 생성이 전체 성공 또는 전체 롤백한다.
- 1,000화에서 최상위 즉시 표시와 하위 지연 로딩이 동작한다.

## 4단계 — 네이티브 편집기

현재 4-1 검증 결과:

- `SmartTextView`와 `iPadTextEditor`로 UTF-8 일반 텍스트 편집 표면 구현
- 문서 ID·외부 버전 기반으로 동일 본문 재주입 방지
- 한글·이모지, UTF-16 커서·선택, 문서별 스크롤, 포커스 요청, Undo/Redo·복사·잘라내기·일반 텍스트 붙여넣기 경계 제공
- 빈 문서 안내를 원문과 분리하고 검색 강조 확장 지점 마련
- 로컬 TXT 로딩과 자동 저장 전 세션 초안 복원
- 4-1 전용 단위 테스트 5개·UI 테스트 1개를 포함해 총 101개 통과
- Mac Catalyst arm64 호환 빌드 통과

현재 4-2 검증 결과:

- `markedTextRange` 조합 중 외부 본문 적용 차단
- 마지막 문서 요청 하나를 pending transition으로 유지하고 조합 완료 후 실행
- background 중 pending 유지와 foreground 후 전환
- `idle`·`focused`·`composing`·`backgrounded`·`restoring` 포커스 상태 머신
- 키보드 언어 강제 변경·키 재전송 없음
- 4-2 전용 단위 테스트 2개를 포함해 단위 테스트 98개·UI 테스트 5개, 총 103개 통과
- iPad Pro 11-inch (M5) 실기기에서 소프트웨어 키보드 한글 조합·겹받침·빠른 화 전환·앱 복귀와 Bluetooth 키보드 입력 확인
- 외장 키보드 반복 입력은 다른 앱에서도 동일하게 비활성 상태여서 앱 결함이 아닌 iPad 설정으로 기록

현재 4-3 검증 결과:
