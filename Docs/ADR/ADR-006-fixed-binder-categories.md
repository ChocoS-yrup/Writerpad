# ADR-006: 고정 바인더 8개

- 상태: 승인
- 날짜: 2026-07-15

## 배경

통합기획서의 플롯·메인 스토리 틀 항목은 AI 집필도우미와 일반 집필프로그램을 혼동해 포함된 것으로 확인됐다.

## 결정

고정 최상위 항목은 원고, 캐릭터, 설정집, 메모장, 흐름 정리, 복선, 장소, 휴지통 8개다. 실제 원고는 `원고/N권/NNN화.txt`에 저장한다. 플롯 자료는 사용자가 일반 문서 영역에 직접 만든 폴더와 TXT로 관리한다.

## 결과

기본 구조와 UI 테스트는 8개를 기준으로 한다. 구형 Windows 작품의 플롯 폴더는 삭제하지 않고 사용자 자료로 보존한다.
