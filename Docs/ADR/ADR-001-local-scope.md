# ADR-001: 로컬 1~7단계 범위

- 상태: 승인
- 날짜: 2026-07-15

## 배경

Supabase와 Windows v2 규약이 확정되는 동안 iPad 로컬 집필 기능을 먼저 개발할 수 있다. 통합 문서에는 AI 집필도우미의 플롯 관련 항목이 섞여 있었다.

## 결정

1~7단계에서는 로컬 작품, 바인더, 편집기, 저장, 백업, 휴지통, 검색, 추출만 구현한다. AI 집필도우미, 플롯·메인 스토리 틀 고정 기능, Supabase 구현은 제외한다.

## 결과

로컬 기능은 서버 없이 완성하고 테스트할 수 있다. 서버 관련 UI를 완료된 기능처럼 표시하지 않는다.
