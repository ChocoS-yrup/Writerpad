# ADR-007: Windows 실제 로컬 경로 호환

- 상태: 승인
- 날짜: 2026-07-15

## 배경

통합기획서의 예시에는 `집필모드/휴지통`이 있었지만 제공된 Windows 소스와 테스트 작품은 모두 `집필모드/메인/휴지통`을 사용한다. Windows는 추가로 `메인/플롯`과 `백업/전환직전`을 만든다.

## 결정

iPad의 휴지통 실제 경로는 Windows와 같은 `메인/휴지통`으로 한다. 화면에서는 계속 최상위 `휴지통`으로 표시한다. 새 iPad 작품은 `메인/플롯`과 `백업/전환직전`을 고정 생성하지 않는다. 기존 Windows 작품을 가져올 때 이 두 폴더는 삭제·이름 변경·자동 병합하지 않고 레거시 사용자 자료로 보존한다.

## 결과

Windows 작품의 휴지통 경로를 별도 변환 없이 인식할 수 있다. 가져오기 화면은 레거시 폴더가 보존됐음을 경고가 아닌 정보로 표시해야 한다.
