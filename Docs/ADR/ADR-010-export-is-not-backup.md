# ADR-010: 원고 내보내기와 백업의 분리

- 상태: 승인
- 날짜: 2026-07-26

## 배경

초기 7-5 계획은 작품 폴더 구조와 UUID·경로 manifest를 함께 내보내고 다시 가져오는 복구용 패키지를 요구했다. 이후 사용자는 내보내기의 목적을 작품 복원이나 백업이 아닌 개인 소장과 열람으로 확정했고, 결과 형식을 TXT와 PDF로 지정했다.

## 결정

1. 사용자에게 제공하는 `원고 내보내기` 형식은 UTF-8 TXT와 PDF다.
2. 두 형식은 동일한 화수 범위와 내용 옵션을 사용한다.
3. 내보내기 직전에 편집 중인 원고를 저장하고, 저장 또는 IME 조합 완료에 실패하면 내보내기를 시작하지 않는다.
4. 내보내기는 원본 원고를 변경하지 않으며, 생성 실패나 취소 시 기존 출력 파일을 보존한다.
5. 작품 폴더, UUID, 내부 상대 경로, manifest, 다시 가져오기 기능은 소장용 내보내기에 포함하지 않는다.
6. 자동 백업·복원과 삭제 작품 보관 정책은 기존 전용 저장소와 절차를 계속 사용하며 내보내기 파일에 의존하지 않는다.

## 결과

TXT는 다른 편집기에서 활용하기 쉬운 원문 사본을 제공하고, PDF는 고정된 A4 페이지로 열람·보관할 수 있다. 이 파일만으로 WriterPad 작품 상태를 복원할 수 있다고 안내하지 않는다. 향후 복구용 패키지가 필요해지면 별도 요구사항과 파일 형식, 호환성 정책을 먼저 확정한다.
