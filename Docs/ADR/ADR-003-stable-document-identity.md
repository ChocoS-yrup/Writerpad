# ADR-003: UUID 문서 정체성과 경로 분리

- 상태: 승인
- 날짜: 2026-07-15

## 배경

파일 이름과 위치는 사용자 작업으로 바뀌지만 커서, 백업, 휴지통, 향후 동기화 기록은 같은 문서에 연결되어야 한다.

## 결정

프로젝트와 문서에 안정적인 UUID를 부여한다. 상대 경로는 현재 위치일 뿐 정체성이 아니다. 이름 변경, 이동, 휴지통 이동 후에도 UUID를 유지한다.

## 결과

경로 기반 중복 문서 생성을 막을 수 있다. 가져오기와 외부 파일 변경 시 기존 UUID를 재조정하는 규칙이 필요하다.
