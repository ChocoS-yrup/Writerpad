# ADR-005: Windows·iPad 공통 파일명 정책

- 상태: 승인
- 날짜: 2026-07-15

## 배경

iPad에서 생성한 이름이 Windows에서 열리지 않거나 다른 이름과 충돌하면 무손실 호환이 불가능하다.

## 결정

`< > : " / \ | ? *`, 제어 문자, 끝 공백·마침표, `.`·`..`, Windows 예약 이름을 거부한다. 같은 부모에서 Unicode NFC 정규화와 대소문자 비구분 후 같은 이름을 중복으로 본다. 모든 경로는 프로젝트 루트 안인지 재검증한다.

## 결과

iPad에서 허용되는 이름이 일부 줄어들지만 Windows 내보내기·가져오기 충돌을 예방한다. 정확한 길이 제한은 Windows v2 소스 확인 후 PathPolicy 설정값으로 확정한다.
