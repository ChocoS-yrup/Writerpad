# ADR-002: UTF-8 TXT를 본문 단일 원본으로 사용

- 상태: 승인
- 날짜: 2026-07-15

## 배경

Windows 작품과 호환하고 앱 데이터베이스 손상 시에도 원고를 직접 복구할 수 있어야 한다.

## 결정

문서 본문은 UTF-8 `.txt` 파일에만 저장한다. SwiftData에는 UUID, 상대 경로, 부모, 정렬, 해시, 수정 시각, 화면 상태 등 메타데이터만 저장한다.

## 결과

본문 중복과 어느 저장소가 최신인지에 대한 혼란을 줄인다. 파일과 메타데이터가 어긋난 경우 TXT를 보존한 채 메타데이터를 재조정해야 한다.
